# Time Track System privacy policy

Public policy for Time Track System (on-device name: Track Time).

Live page: https://arcself.github.io/time-track-system-privacy/

GitHub Pages serves `index.html` from the root of `main`. No build, JavaScript, analytics, or external assets are required.

Policy changes should be checked against the shipping app and dated in the page. This repository contains only public policy materials, not application source or user records.
